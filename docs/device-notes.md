# Device notes

Device verification is pending. Exercise launch, one interaction, sleep, wake, Done, reopen, and removal from the
launcher and Store before a device release.

With the matching Launcher, leave Notes open and connect the Kindle drive to a computer. Edit a saved note and add
a new `.txt` file in `notes/`. Eject the drive and verify Notes shows both changes. Use disposable notes to check
that a saved edit survives restarting the Kindle. Record whether the Kindle filesystem persists directory changes
across a controlled interruption.
